# luci-theme-bootstrap-dark

Тёмная тема для LuCI на **OpenWrt 19.07**, визуально близкая к стандартной теме `bootstrap`
и сделанная по образцу тёмного режима в новых версиях OpenWrt (22.03 / 23.05).

## Особенности

- Не заменяет стандартную тему. Устанавливается отдельным пунктом **BootstrapDark** в разделе
  *Система → Система → Язык и тема → Тема оформления*.
- Только CSS: ничего не нужно собирать или компилировать.
- Покрывает главную страницу, интерфейсы, мониторинг, формы, динамические списки, таблицы,
  вкладки, выпадающие списки, кнопки, уведомления и модальные окна.
- Переживает обновление прошивки (`sysupgrade`) благодаря записям в `/etc/sysupgrade.conf`.

## Требования

- OpenWrt 19.07 (проверено на 19.07.10)
- установленная и **неизменённая** тема `luci-theme-bootstrap` (по умолчанию она есть)

## Установка

### Вариант 1: копирование с компьютера (рекомендуется)

1. Скачайте репозиторий архивом (**Code → Download ZIP**) и распакуйте его.
2. Скопируйте папку на роутер и запустите установщик:

```sh
scp -O -r luci-theme-bootstrap-dark root@192.168.1.1:/tmp/
ssh root@192.168.1.1
sh /tmp/luci-theme-bootstrap-dark/install.sh
```

> Ключ `-O` включает у `scp` старый протокол, который нужен OpenWrt 19.07 (Dropbear)
> при работе с современными клиентами OpenSSH. В Windows 10/11 `scp` и `ssh` доступны в PowerShell.

### Вариант 2: клонирование на роутере

```sh
opkg update && opkg install git git-http
git clone https://github.com/<USER>/luci-theme-bootstrap-dark.git
cd luci-theme-bootstrap-dark
sh install.sh
```

### Включение

Обновите страницу в браузере (Ctrl+F5), откройте *Система → Система → Язык и тема*,
выберите **BootstrapDark** и нажмите «Сохранить и применить».

Чтобы тема включилась сразу, запустите установщик с ключом `--activate`:

```sh
sh install.sh --activate
```

### Что делает установщик

- копирует тему `bootstrap` в `bootstrap-dark` и дописывает тёмный CSS;
- регистрирует тему в UCI (`luci.themes.BootstrapDark`);
- добавляет пути темы в `/etc/sysupgrade.conf`;
- очищает кэш LuCI.

Установщик откажется работать, если в стандартной теме `bootstrap` уже есть тёмный CSS
(например, дописанный вручную). Сначала восстановите оригинальный `cascade.css`
или переустановите `luci-theme-bootstrap`.

## Удаление

```sh
sh uninstall.sh
```

Скрипт при необходимости возвращает активную тему на `bootstrap`, удаляет файлы темы и запись в UCI,
а также убирает строки из `/etc/sysupgrade.conf`.

## Альтернатива: автоматический тёмный режим

Если нужна одна тема, которая становится тёмной только когда ОС или браузер используют тёмный режим,
допишите `bootstrap-dark.css` как есть в конец `/www/luci-static/bootstrap/cascade.css`:

```sh
cp /www/luci-static/bootstrap/cascade.css /root/cascade.css.bak
cat bootstrap-dark.css >> /www/luci-static/bootstrap/cascade.css
```

Файл обёрнут в `@media (prefers-color-scheme: dark)`, поэтому в светлом режиме он ни на что не влияет.
Не совмещайте этот способ с `install.sh` (см. примечание выше).

## Настройка цветов

Все цвета заданы CSS-переменными в начале файла `bootstrap-dark.css`:

```css
--bg: #1b1b1b;        /* страница */
--bg-card: #242424;   /* секции, таблицы */
--bg-alt: #2b2b2b;    /* чередующиеся строки, заголовки таблиц */
--bg-input: #181818;  /* поля ввода */
--text: #e4e4e4;
--accent: #5ea1f0;
```

Измените их и запустите `install.sh` снова, чтобы применить свою палитру.

## Известные ограничения

- Графики на странице мониторинга перекрашиваются инверсией всего графика, поэтому оттенки
  могут слегка отличаться от оригинала.
- Тема рассчитана на OpenWrt 19.07. В более поздних версиях (21.02+) у `bootstrap` другая вёрстка
  и есть собственный тёмный режим.
- Сторонние пакеты `luci-app-*` со своим CSS могут по-прежнему содержать светлые элементы.
