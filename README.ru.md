# luci-theme-bootstrap-dark

Тёмная тема для LuCI на **OpenWrt 19.07**, визуально близкая к стандартной теме `bootstrap`
и сделанная по образцу тёмного режима в новых версиях OpenWrt (22.03 / 23.05).

## Особенности

- Не заменяет стандартную тему. Устанавливается отдельным пунктом **BootstrapDark** в разделе
  *Система → Система → Язык и тема → Тема оформления*.
- Экономит ресурсы: около 24 КБ CSS (5 КБ в gzip), без JavaScript, веб-шрифтов и дополнительных картинок,
  дополнительные пакеты на роутер не нужны. См. [«Занимаемое место»](#занимаемое-место).
- Всегда тёмная: без трюков с `@media`, тема выглядит одинаково при любых настройках браузера.
- Покрывает главную страницу, интерфейсы, мониторинг, формы, динамические списки, таблицы, вкладки,
  выпадающие списки, кнопки, уведомления и модальные окна.
- Переживает обновление прошивки (`sysupgrade`) при сохранении настроек благодаря записям
  в `/etc/sysupgrade.conf`.

## Требования

- OpenWrt 19.07 (проверено на 19.07.10)
- установленная и **неизменённая** тема `luci-theme-bootstrap` (по умолчанию она есть)

## Установка

### Вариант 1: одна команда на роутере (рекомендуется)

Роутеру нужен доступ в интернет и правильное системное время. На чистой OpenWrt 19.07 пакеты для
загрузки по HTTPS обычно не установлены, поэтому сначала установите их (это нужно сделать один раз).
Затем запустите установщик, обе команды выполняются по SSH:

```sh
opkg update && opkg install ca-bundle libustream-mbedtls
wget -O - https://raw.githubusercontent.com/CorvusSteam/luci-theme-bootstrap-dark/main/install.sh | sh
```

Скрипт сам скачивает `bootstrap-dark.css`. Нужен только `wget`, который входит в состав OpenWrt.
Скачанный файл проходит через `/tmp` (оперативная память) и удаляется после установки; установленная
тема занимает место на флеш-памяти (см. [«Занимаемое место»](#занимаемое-место)). Скрипт можно
сначала прочитать, открыв этот же адрес в браузере.

Если `wget` всё равно сообщает об ошибке сертификата, проверьте время командой `date`: при неверных
часах проверка сертификата не проходит.

Если основная ветка репозитория называется не `main` (например, `master`), замените её в адресе.

### Вариант 2: копирование с компьютера

Подходит, если у роутера нет доступа в интернет.

1. Скачайте репозиторий архивом (**Code → Download ZIP**) и распакуйте его.
2. Скопируйте папку на роутер и запустите установщик:

```sh
scp -O -r luci-theme-bootstrap-dark root@192.168.1.1:/tmp/
ssh root@192.168.1.1
sh /tmp/luci-theme-bootstrap-dark/install.sh
```

> Ключ `-O` включает у `scp` старый протокол. В OpenWrt 19.07 (Dropbear) нет SFTP-сервера,
> а OpenSSH 9.0+ по умолчанию использует SFTP. В Windows 10/11 `scp` и `ssh` доступны в PowerShell.

### Включение

Обновите страницу в браузере (Ctrl+F5), откройте *Система → Система → Язык и тема*,
выберите **BootstrapDark** и нажмите «Сохранить и применить».

Чтобы тема стала активной сразу после установки, добавьте ключ `--activate`
(первая команда для Варианта 1, вторая для Варианта 2):

```sh
wget -O - https://raw.githubusercontent.com/CorvusSteam/luci-theme-bootstrap-dark/main/install.sh | sh -s -- --activate
sh /tmp/luci-theme-bootstrap-dark/install.sh --activate
```

### Что делает установщик

- копирует тему `bootstrap` в `bootstrap-dark` и дописывает тёмный CSS;
- регистрирует тему в UCI (`luci.themes.BootstrapDark`);
- добавляет пути темы в `/etc/sysupgrade.conf`;
- делает имя роутера в шапке ссылкой на страницу «Состояние» (в стандартной теме оно лишь
  добавляет `#` в адрес);
- очищает кэш LuCI и выводит размер установленной темы.

Установщик откажется работать, если в стандартной теме `bootstrap` уже есть тёмный CSS
(например, дописанный вручную). Сначала восстановите оригинальный `cascade.css`
или переустановите `luci-theme-bootstrap`.

## Удаление

```sh
wget -O - https://raw.githubusercontent.com/CorvusSteam/luci-theme-bootstrap-dark/main/uninstall.sh | sh
```

Если скачанная папка ещё есть, вместо этого можно запустить `sh uninstall.sh` из неё.

Скрипт при необходимости возвращает активную тему на `bootstrap`, удаляет файлы темы и запись в UCI,
а также убирает строки из `/etc/sysupgrade.conf`.

## Занимаемое место

- **Флеш-память:** установщик копирует стандартную тему `bootstrap` и дописывает тёмный CSS, поэтому
  установленная тема занимает примерно столько же, сколько стандартная, плюс 24 КБ (около 58 КБ CSS
  плюс картинки стандартной темы). Точные цифры выводит установщик. Файловые системы флеш-памяти
  сжимают данные, так что реальный расход ниже.
- **RAM роутера:** CSS отдаётся с флеш-памяти. В память загружаются только шаблоны активной темы.
  Файл, скачанный установщиком в `/tmp`, удаляется сразу после установки.
- **Браузер:** один стиль на 24 КБ поверх стандартного, без скриптов и дополнительных запросов.

## Настройка цветов

Все цвета заданы CSS-переменными в начале файла `bootstrap-dark.css`:

```css
--bg: #1b1b1b;        /* страница */
--bg-card: #242424;   /* секции, таблицы */
--bg-alt: #2b2b2b;    /* чередующиеся строки, заголовки таблиц */
--bg-input: #181818;  /* поля ввода */
--text: #e4e4e4;
--accent: #5ea1f0;
```

Чтобы изменить их, отредактируйте `bootstrap-dark.css` до запуска `install.sh` (для этого удобнее
всего Вариант 2) либо отредактируйте `/www/luci-static/bootstrap-dark/cascade.css` на роутере после
установки. Чтобы увидеть результат, обновите страницу через Ctrl+F5.

## Известные ограничения

- Графики на странице мониторинга перекрашиваются инверсией всего графика, поэтому оттенки
  могут слегка отличаться от оригинала.
- Тема рассчитана на OpenWrt 19.07. В версиях 22.03 и новее у `bootstrap` другая вёрстка и есть
  собственный тёмный режим, поэтому для них эта тема не предназначена.
- Сторонние пакеты `luci-app-*` со своим CSS могут по-прежнему содержать светлые элементы.
- На узких экранах (телефоны) макет такой же, как в стандартной теме `bootstrap` для 19.07,
  которая не адаптивна. Тема меняет только цвета, но не вёрстку.
- Несколько правил используют CSS-селектор `:has()` (страница входа, «Применить» в окне изменений).
  Нужен Chrome/Edge 105+, Firefox 121+ или Safari 15.4+; в более старых браузерах эти элементы
  просто остаются с обычным видом.

## Версии

См. [CHANGELOG.md](CHANGELOG.md) и страницу Releases этого репозитория.

- **v3.0**: таблица стилей переработана и очищена (на 27% меньше, 13 разделов с подписями), тема
  всегда тёмная (необязательный режим «авто» из v2.x удалён).
- **v2.1**: много исправлений цветов и читаемости, найденных при проверке страница за страницей.
- **v2.0**: имя роутера в шапке страницы открывает страницу «Состояние».
- **v1.0**: первый выпуск.

Ветка `main` всегда содержит последнюю версию.
